# Toyota Đồng Tháp

Website đại lý Toyota Đồng Tháp — tĩnh HTML/CSS/JS, không cần build.

- **Địa chỉ**: Quốc lộ 30, Thành phố Cao Lãnh, tỉnh Đồng Tháp
- **Hotline**: 0772 223 330

## Cấu trúc

- `index.html` — Trang chủ
- `xe.html` — Bảng giá xe
- `lien-he.html` — Liên hệ & đặt lịch lái thử
- `css/style.css` — Style dùng chung
- `js/main.js` — Script dùng chung (menu mobile, lọc xe, form)

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc dùng một static server bất kỳ (vd. `npx serve`).

Logo và hình xe là SVG minh họa tự vẽ, chưa phải logo/ảnh chính thức của Toyota. Giá xe là giá tham khảo, cần cập nhật theo thực tế.
