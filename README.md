## Cấu trúc

- `index.html` — Trang chủ
- `xe.html` — Bảng giá xe
- `lien-he.html` — Liên hệ & đặt lịch lái thử
- `css/style.css` — Style dùng chung
- `js/main.js` — Script dùng chung (menu mobile, lọc xe, form)
- `images/cars/` — Ảnh xe (nguồn: toyotadongthap.vn và Wikimedia Commons)
- `images/promo/` — Ảnh minh họa khuyến mãi/dịch vụ

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc dùng một static server bất kỳ (vd. `npx serve`).

## Triển khai

- **GitHub Pages**: tự động cập nhật khi push lên nhánh `main`
- **Vercel**: đã kết nối với repo GitHub này, tự động build & deploy khi có commit mới

Giá xe là giá tham khảo, cần cập nhật theo thực tế đại lý.
